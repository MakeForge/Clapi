# Implementation Plan: gRPC Request Proto Folder Workflow

**Branch**: `032-grpc-proto-workflow` | **Date**: 2026-11-20 | **Spec**: [spec.md](spec.md)
**Input**: Feature specification from `/specs/032-grpc-proto-workflow/spec.md` + user reminder to update docs and tests as needed.

## Summary

Rework the gRPC request proto workflow so users can select an entire proto folder in `SelectProtoFileDialog`, pick a specific `.proto` file from that folder (and its subdirectories), and automatically resolve imports against the selected folder hierarchy plus all enabled collection-wide import paths and collection proto files. Consolidate the request-level "Sync to Git" toggle out of `GrpcRequestBar` into `SelectProtoFileDialog`, and extend `ProtoPathResolver` / `CollectionStorageDriver` to recursively sync all `.proto` files (excluding non-`.proto` files and cleaning stale files) when a proto folder is synced to Git. Update user documentation and unit/UI/E2E tests to cover all new flows.

## Technical Context

**Language/Version**: Kotlin 2.1.21 (Kotlin Multiplatform targeting `jvm("desktop")`), JDK 25  
**Primary Dependencies**: Compose Multiplatform 1.8.1, Material 3, FileKit (`openDirectoryPicker` / `openFilePicker`), `protoc-jar` (`ProtocJarParser`), `kotlinx.serialization`, JUnit / Compose Desktop UI Test  
**Storage**: OpenCollection v1.0.0 YAML/JSON files (via `OpenCollectionModelMapping` + `clapi` extensions), local tab state (`TabsRepository`), Git working copy (`ProtoPathResolver` + `CollectionStorageDriver`)  
**Testing**: `:core-network:desktopTest`, `:core-storage:desktopTest`, `:ui-shared:desktopTest`, `:ui-desktop:desktopTest`, `:qa-tests:jvmTest` (all invoked via `rtk gradlew ...`)  
**Target Platform**: Desktop JVM (Linux, macOS, Windows)  
**Project Type**: Desktop API Client (multi-module KMP Gradle project)  
**Performance Goals**: Instant recursive `.proto` scan for typical proto directories (<100ms), responsive dialog scrolling with `VerticalScrollbar`  
**Constraints**: Preserve 100% OpenCollection v1.0.0 schema compatibility and backward compatibility with existing single-file and collection-level gRPC requests; follow `create-compose-ui-kmp-desktop` guidelines; keep `core-*` modules free of UI dependencies  
**Scale/Scope**: Touches `core-storage`, `core-network` (tests/verification), `ui-shared`, `ui-desktop` (tests), `qa-tests`, and `docs/`
