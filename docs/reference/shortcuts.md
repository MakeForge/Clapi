# Keyboard Shortcuts Cheat Sheet

## Global Application Shortcuts

| Action | macOS Shortcut | Windows / Linux Shortcut |
|---|---|---|
| **Send Active Request** / Cancel in-flight | `⌘ + Enter` | `Ctrl + Enter` |
| **Save Active Request** | `⌘ + S` | `Ctrl + S` |
| **New Request Tab** | `⌘ + N` | `Ctrl + N` |
| **Close Active Tab** | `⌘ + W` | `Ctrl + W` |
| **Open Settings** | `⌘ + ,` | `Ctrl + ,` |
| **Move Active Tab Left** | `⌘ + Shift + [` | `Ctrl + Shift + [` |
| **Move Active Tab Right** | `⌘ + Shift + ]` | `Ctrl + Shift + ]` |
| **Focus Search / Filter** | `⌘ + F` | `Ctrl + F` |

## Code Editor Shortcuts

Inside the JSON, GraphQL, and Script code editors:

| Action | macOS Shortcut | Windows / Linux Shortcut |
|---|---|---|
| **Format Document / Prettify** | `Shift + Option + F` | `Shift + Alt + F` |
| **Toggle Line Comment** | `⌘ + /` | `Ctrl + /` |
| **Duplicate Line Down** | `Shift + Option + ↓` | `Shift + Alt + ↓` |
| **Move Line Up / Down** | `Option + ↑ / ↓` | `Alt + ↑ / ↓` |
| **Fold / Unfold Code Block** | `⌘ + Option + [` / `]` | `Ctrl + Shift + [` / `]` |
| **Jump to Document Start / End** | `⌘ + ↑ / ↓` | `Ctrl + Home / End` |
