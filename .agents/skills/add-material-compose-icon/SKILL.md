# Manage Compose Vector Icons

Standardized procedure for fetching, generating, and rendering Android Vector XML icons in Compose Multiplatform (CMP Desktop) projects.

## When to Use

- Adding a new icon asset to the project's drawable resources.
- Migrating away from `Icons.Default.*`, `Icons.Filled.*`, or `Icons.AutoMirrored.*` to `Res.drawable.*`.
- Resolving missing icon compilation errors (`Unresolved reference: ic_*`).

---

## 1. Directory & File Naming Conventions

- **Target Directory:**
  `ui-shared/src/commonMain/composeResources/drawable/`
- **File Naming:**
  Always use lowercase snake_case prefixed with `ic_`:
  - `visibility` -> `ic_visibility.xml`
  - `arrow_back` -> `ic_arrow_back.xml`
  - `view_sidebar` -> `ic_view_sidebar.xml`

---

## 2. Vector XML Specifications

Every icon must be an Android Vector XML (`<vector>`) with `24dp` viewport dimensions and `#FF000000` fill color. Hardcoding pure black fill ensures Compose dynamic tinting (`tint = ClapiColors.*` / `LocalContentColor`) masks the paths accurately.

```xml
<vector xmlns:android="http://schemas.android.com/apk/res/android"
    android:width="24dp"
    android:height="24dp"
    android:viewportWidth="24"
    android:viewportHeight="24">
  <path
      android:fillColor="#FF000000"
      android:pathData="<SVG_OR_VECTOR_PATH_DATA>"/>
</vector>
```

---

## 3. Automation: Fetching via Helper Script

Use the helper script `../../../scripts` to fetch, convert, and place vector XML drawables:

### Fetch One or More Specific Icons:
```bash
python3 scripts/fetch_icon.py visibility
python3 scripts/fetch_icon.py ic_menu ic_view_sidebar ic_format_align_left
```

### Scan Project & Auto-Download All Missing Icons:
```bash
python3 scripts/fetch_icon.py --scan
```

---

## 4. Usage in Compose Multiplatform

### Required Imports

The package generated by Compose Multiplatform for the `ui-shared` module uses an underscore: `io.github.crustack.clapi.ui.shared.generated.resources.*`.

```kotlin
import io.github.crustack.clapi.ui.shared.generated.resources.Res
import io.github.crustack.clapi.ui.shared.generated.resources.ic_visibility
import org.jetbrains.compose.resources.painterResource
```

### Basic Rendering

Always supply `painter = painterResource(...)`. Never pass `painterResource` into `imageVector`.

```kotlin
Icon(
    painter = painterResource(Res.drawable.ic_visibility),
    tint = ClapiColors.OnSurfaceVariant,
    modifier = Modifier.size(16.dp)
)
```

### Conditional Rendering (Ternary / When)

```kotlin
Icon(
    painter = if (state.isVisible) {
        painterResource(Res.drawable.ic_visibility)
    } else {
        painterResource(Res.drawable.ic_visibility_off)
    },
    contentDescription = null,
    tint = ClapiColors.OnSurfaceVariant
)
```

## 5. Verification & Compilation

Recompile the project to verify that Compose Multiplatform generates the typed resource accessors:

```bash
./gradlew compileKotlinDesktop
```
Ensure zero `Unresolved reference: ic_*` compilation errors occur.
